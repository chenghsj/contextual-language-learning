# Code of Conduct

This project welcomes respectful collaboration regardless of experience, identity, background or skill level.

Be constructive in reviews and issues. Focus criticism on the code and observable behavior. Respect differing opinions, give others time to respond, and never post harassment, threats, hate speech, sexualized remarks, personal information, credential material or copyrighted media you do not have permission to share.

Maintainers may edit or remove abusive comments, close disruptive threads and restrict participation when needed. Avoid posting sensitive reports in public GitHub issues. For a GitHub-hosted harassment or abuse incident, use GitHub's built-in report controls; for a security vulnerability use [SECURITY.md](SECURITY.md). If the maintainer publishes a dedicated private conduct contact, use it for confidential project-specific reports.

Decisions about project scope, moderation and contributions are made by the maintainer in accordance with this policy. Participants are expected to comply in repository issues, pull requests, discussions and other project spaces.
