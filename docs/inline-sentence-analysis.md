# 情境語塊與原句下方解析

實作日期：2026-10-08。標準 V5 教材流程；自訂提示詞流程維持原有呈現方式。

## 使用方式

- 建立教材時，「解說偏好」提供每類一個「關閉／一般／詳細」選單，預設全部「一般」：「字詞與搭配、文法與句型、語句拆解、語氣與用法、讀音與聽辨、文化與背景」。可全部關閉，情境、原文、翻譯與基本意思仍保留。
- 可將多個類別設為「詳細」以著重解說；「一般」提供理解本句所需的核心說明，「詳細」在相同程度下增加有用的組合、原因、差異或使用限制。「關閉」不生成該類補充並移除著重狀態。沿用既有 enabledExplanations／emphasizedExplanations 與 preferencesV2，舊偏好自動對應選單，不改寫已建立教材。
- 原句解析預設收合。點語塊或「解析」後，內容出現在對應原句下；跨相鄰字幕的解析放在最後一行下。一次只開一份解析，多個解說類別可以同時展開。
- 第一次展開時優先打開有內容的著重類別；後續保留手動展開狀態。切換場景收合解析。播放進度只更新播放標示，不觸發捲動或改變選取語塊。
- 原句右側播放按鈕和語塊選取是獨立操作。「閱讀顯示設定」只隱藏教材已有內容，不呼叫模型。
- 舊教材的重點意思、情境解說、字詞補充與 AI 例句移至來源原句下；不假造新的語塊或缺少的類別。

## 資料與生成契約

保留 schemaVersion 5，以可選欄位擴充：

- LearningProfile.enabledExplanations / emphasizedExplanations：缺少欄位等同六類全開、均衡。
- ContextualScene.sentenceAnalyses：原句來源 ID、對應 focusIndexes、chunks、分類 notes。
- Chunk.spans：原始字幕 cueId 與 UTF-16 start/end 範圍，保留原文空白、標點與可對齊的讀音。
- Chunk.meaning / role：片段意思與組合關係。reusablePattern 是可重用表達或框架，另存並標示，不能冒充原片原文。

Host 檢查來源 ID、來源順序、共句重點、重複解析 ID、語塊範圍、重疊及 Unicode 邊界；無法對齊的語塊不呈現為可點選內容，保留可用的基本解說。停用的分類補充、字詞補充與讀音會在 Host 邊界移除。這些驗證能確認來源定位與資料結構，不能自動證明模型的語義解說正確。

候選、全片篩選、教學三階段均注入語言、程度、啟用類別與著重偏好。教學一次產生重點原句解析；點選語塊不增加模型呼叫。12 種語言皆有基本選材、拆解與解說策略；讀音沿用日文假名、韓文可靠音變、其餘語言可靠 IPA，不能推定原片的實際語調。

六類一般／詳細規則在教學階段注入：字詞補充相關詞義與搭配限制、文法解釋形式與意思、拆解說明組合及可重用框架、語用對照表達差異、讀音區分一般規則與錄音實際發音、文化限有來源的必要背景。同一知識點只完整解釋一次；不設最低字數或補充數量，沒有可靠的額外價值就不擴寫。不因詳細提高程度、場景、重點或例句數。設計依據及研究限制見 [解說深度研究](./explanation-depth-research.md)。

工作流程版本為 scene-v5-2，提示詞版本為 scene-prompts-3。完整請求包含偏好並納入 execution inputFingerprint；舊版本（含 scene-prompts-2）或沒有凍結身分的正式任務不能續跑，保留 checkpoint 並要求重新建立。離線測試注入生成器時保留既有測試續跑能力。

## 本影片其他出現

在已保存字幕中本機搜尋已選表達，不呼叫模型。支援相同文字、大小寫、彎引號與空白排版差異；跨相鄰字幕可匹配，已知時間差超過兩秒則不跨越。依語言處理文字邊界，不搜尋詞形變化或抽象句型。

每個實際位置分別計數，同一字幕內重說也保留。排除目前教學位置的一次匹配後，列出其他位置、實際原文、相鄰字幕及可用時間，每次增加五筆。相同文字不自動套用同一翻譯或意思。搜尋涵蓋範圍明確標示為已保存字幕；有 analysisRange 時顯示範圍，不能宣稱搜尋未保存的全片字幕。

有時間的位置透過既有播放器回看並套用已保存字幕校準；跨字幕用完整時間範圍。無時間仍能閱讀。其他出現不提供會誤改教學原句的校準操作。AI 延伸例句另列並保留來源標示。

## 保存與相容

完整 JSON、Markdown、Host 保存、發布與備份保留新增內容。還原經過同一份 V5 schema。時間校準只改 playbackOverrides，不改原文與字元範圍。既有 compactStudyExport 保留精選字幕的用途，不作為完整字幕搜尋或備份的來源。
