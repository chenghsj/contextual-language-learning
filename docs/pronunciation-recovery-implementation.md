## 行為與安全邊界

- 新輸出使用純函式處理，複製資料後只對 `reading` 做 NFC、首尾空白處理；日語標準片假名與反覆符號轉為平假名，保留長音。半形假名、漢字、羅馬字不猜測。韓語維持 Hangul，其餘十語言維持斜線格式。來源文字、ID、時間與例句文字不改寫。
- 原始標註的文字對齊、來源、完整原句覆蓋、引用與例句結構先驗證。只有讀音格式或空讀音可以修復／降級；錯誤對齊不得因刪除標註而通過。
- 批次共用一次自動修復額度。讀音修復只接受指定標註位置的 segments；翻譯、學習重點與框架不在契約內。失敗時保留有效片段讀音，移除不可靠 reading；完全沒有有效讀音則省略整組標註，完整驗證後交付。
- 修復呼叫前先保存有效教學草稿、待修復位置、診斷及已保留額度。中斷後從草稿繼續；已開始的自動修復不再重發。手動續跑結構問題時帶入最近診斷，成功批次不重跑，也不重設額度。
- 成功結果、最終診斷與 execution metadata 在同一次儲存更新內保存。穩定診斷 ID 去重，缺漏按受影響標註位置計數。單純沒有提供可選標註、或 Pronunciation Off，不增加缺漏數。
- 閱讀頁顯示「部分讀音未提供」，任務列表顯示缺漏數，詳細資訊列出處理原因。表記轉換只出現在詳細資訊。JSON／Markdown、Drive 還原及分塊傳輸保留診斷；V5 仍讀取既有內容。
- 三階段可選對話、獨白或歌詞段落，不要求兩位說話者。歌詞保留省略、倒裝及意象，要求不確定處明示、不補造角色、故事或音訊細節；重複副歌按用法合併，延伸例句區分詩性用法與日常情境。
