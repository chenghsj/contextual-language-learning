## 已完成的程式

- 統一有效思考強度、預估與模型輸出預算；保留明確選擇，並將新設定凍結於 execution。舊任務只對後續呼叫記錄有效設定，不改寫原始 request／指紋或歷史呼叫。
- 新增 `compact-scenes-1` 實驗策略：精簡候選輸出，僅對入選場景建立完整來源單元與教學；保留全部來源、啟用類別和例句要求。
- 建立版本化 checkpoint、並行度 2 的場景排程、429 降速與有限修補／擴額。已收到的輸出先保存；取消、失敗或重啟後沿用完成場景與 pending 輸出。
- 增加跨場景等價索引及驗證，保留原 point/item ID 與各場景的來源範圍；閱讀呈現可以共用已確認等價的內容。
- 接上 `getJobPreview`：使用既有 `job` 摘要與 `result`／`documentChunk` 傳輸，同一 snapshot 的 revision、ready IDs 與教材內容綁定。保留相容的 protocol 16，沒有以相同版本引入不相容的新回應類型。
- 活動列表可開啟完成場景；閱讀器顯示剩餘進度，插入較早場景不改變目前閱讀位置。部分教材尚未正式保存前不提供收藏、時間校正或 Web 開啟；完成後恢復這些操作。
- 對兩種已觀察到的 JSON 語法錯字加入有限正規化：物件起始括號後多出的行尾反斜線，以及 source span 整數後多出的引號。只處理字串外的指定形狀，記錄診斷，仍要求完整 JSON 與全部來源／教學驗證，不修補任意內容或截取散落物件。
- 不可靠的選填讀音可省略並記錄診斷；來源文字、翻譯、教學與例句不因此改寫。未知來源引用、重複引用或未啟用的讀音欄位仍會拒絕。

正式建立任務仍預設走既有流程；只有顯式傳入 `generationStrategy: "compact-scenes-1"` 的測試入口才使用新流程。正式輸入預估同樣保留既有預設，避免以較小實驗 prompt 低估目前正式請求。
