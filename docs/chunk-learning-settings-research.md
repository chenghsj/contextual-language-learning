# 以語塊理解影片：是否需要六類解說設定？

查核日期：2026-10-09。研究範圍：以影片原句、有意義語句切分與可重用表達為核心的學習流程，是否需要讓使用者在生成前分別設定「字詞與搭配、文法與句型、語句拆解、語氣與用法、讀音與聽辨、文化與背景」的關閉／一般／詳細。

## 結論與證據強度

**建議取消標準語塊學習流程中的六類前置選單，保留系統內部的教學角度，將必要解說整合在原句／語塊上，讓使用者在閱讀時控制延伸內容與讀音顯示。** 這是根據教學資料、學習研究、產品目標與原始碼做出的設計建議，不是已由實驗證明的最佳介面。

查核來源沒有直接比較這六個選單的保留／取消，也沒有證明每句或每場景應固定有幾個學習點。不能從「語塊有學習價值」推導成「所有句子都要切分」，或從「資訊負擔有風險」推導成「文法、語用、讀音全部取消」。

## 先區分兩種語塊

1. **理解片段**：為理解某一句而辨識條件、主要動作、修飾與從屬關係。它可能是自由組合的子句，不因此成為可以整體背誦的固定表達。
2. **可重用表達**：固定／半固定搭配、慣用語、可替換槽位的句型框架。可以另教意思、使用條件與替換方式。

British Council 的作者教學文章把 lexical chunks 說明為常一起出現的詞組，也明確討論搭配與文法模式的關聯；UT Austin 的教材開發課程包含固定表達、搭配與句型框架。這支持「以表達為中心，整合必要的文法與用法」，不支持把任意字幕切片都當成固定語塊。[British Council 原作者文章](https://www.teachingenglish.org.uk/professional-development/teachers/knowing-subject/lexical-approach-1-what-does-lexical-approach)、[UT Austin／COERLL 原課程](https://coerll.utexas.edu/methods/modules/vocabulary/02/lexical.php)。

兩份資料是教學概念與教材設計來源，沒有在本產品進行有效性實驗。UT Austin 網站已於 2026-03-02 封存。

## 研究支持什麼

### 1. 可以透過影片學表達，仍受先備知識影響

Puimège、Peters（2020 刊期；2019 線上）讓 42 位荷蘭語背景英語學習者觀看一小時無字幕紀錄片，測量形式與意思回想。出版者摘要報告兩者均有增益，先備詞彙與增益有正向關聯，觀看前已知表達意思尤其能預測形式學習。[原論文摘要](https://doi.org/10.1017/S027226311900055X)。

這是受試者內前後測，並未比較六類設定或不同的切句介面。產品推論：保留意思與情境支援，不能假定標出語塊就完成教學；程度標籤也不能精確代表每位使用者已知哪些表達。

### 2. 將注意力引向表達，可能與理解影片競爭

Majuddin、Boers、Siyanova-Chanturia（2024 線上；2026 刊期）的近似複現，比較無字幕、一般字幕、強調多詞表達的字幕，以及看一次／兩次。強調有助表達學習，但詞彙量較低的學習者在影片內容理解上有不利結果；全文也指出不能將不同影片的跨研究差異只歸因於介入。[原論文全文，摘要、結果與結論](https://doi.org/10.1017/S0261444824000296)。

作者提出先一般字幕理解、再強調重看，作為待驗證方向。它沒有測試本產品的中文解說或折疊介面。產品推論：理解原句優先，延伸知識按需出現；不應同時要求注意所有能教的細節。

### 3. 同一套支援對不同熟練度的人，效用可能不同

Kalyuga、Chandler、Sweller（1998）原研究摘要報告三個實驗：隨熟練度增加，較好的設計從圖文整合轉向移除冗餘文字。[原論文摘要](https://doi.org/10.1518/001872098779480587)。

研究材料是圖文教學，不是語言影片，不能據此宣稱六類下拉選單會降低學習成效。產品推論：避免對熟悉內容重複講解，同時不能讓精簡模式漏掉初學者理解所需的資訊。

### 4. 語塊不能代表全部語言能力

CEFR Companion Volume（2020）官方目錄將溝通能力分成語言、社會語言與語用能力，並更新音韻能力量表。[Council of Europe 官方出版說明與目錄](https://book.coe.int/en/education-and-modern-languages/8150-common-european-framework-of-reference-for-languages-learning-teaching-assessment-companion-volume.html)。

能力框架不能決定本產品要有幾個控制項。它提醒我們：表達的語域、交際功能與讀音仍可能重要；取消選單不應使這些必要支援失去產出途徑。

### 5. 延後次要內容是介面原則，沒有代替內容篩選

NN/g 自有 Progressive Disclosure 指南建議將進階或少用功能放到次要介面。[原指南](https://www.nngroup.com/articles/progressive-disclosure/)。本次頁面直接讀取失敗，依原站搜尋索引內容確認此原則，未使用轉載，也未把它當作語言學習實驗。

產品推論：把延伸解說留給有需要的讀者。但將所有內容先生成、再折疊，只降低初始顯示量，沒有解決內容品質、總量與生成負擔。

## 六類如何取捨：產品建議

以下是設計判斷，尚未實作或做使用者驗證。

| 現有類別   | 標準語塊學習流程的建議                                                           |
| ---------- | -------------------------------------------------------------------------------- |
| 字詞與搭配 | 整合在該語塊的意思或可重用表達中；避免再列每個已容易理解的字                     |
| 文法與句型 | 必要時解釋來源形式怎麼構成意思、哪裡可以替換；不把核心理解交給關閉開關           |
| 語句拆解   | 當作核心理解手段，按句子需要提供可靠片段；簡單句不強拆，不強制全面覆蓋或固定數量 |
| 語氣與用法 | 影響原句理解或日常移用時直接整合；額外的對照再按需展開                           |
| 讀音與聽辨 | 讀音顯示交給閱讀控制；一般縮約可整合在相關語塊，無音訊不推斷演員實際發音         |
| 文化與背景 | 影響原句理解時給短背景；延伸文化知識保持按需且有來源                             |

前置設定優先保留使用者可以明確判斷的學習語言、程度、解說語言、分析範圍與內容份量。預設由系統選必要教學角度；若仍需深度偏好，可保留一個整體深度的進階選項，不再六類各自配置。深度只增加有用對照／限制，不能乘出更多學習點或補齊六類。

閱讀流程建議以「完整原句 → 選中的語塊與意思 → 一段必要解說 → 有需要時看用法對照／延伸例句」組織。必要解說必須先足以理解，不能為了精簡把關鍵條件藏進延伸區。可提供一組有價值的例句作為預設候選方案；更多例句按需取得，但這是待驗證的生成策略，現有程式只做到已有例句的按需顯示。

若教師或進階使用者确實需要「只看語用」「只研究文法」等專項任務，可另保留專用流程或進階覆寫，不讓一般使用者先替系統判斷每句需要哪一種知識。沒有使用證據前，也不應直接刪除舊 profile/schema：先保持舊教材可讀、偏好可解釋，再決定新流程的語義與 execution identity。

## 可以怎樣驗證建議

- 固定同一字幕、程度、模型與來源範圍，比較現行六類設定與自動整合解說；不能因換模型／換字幕，把差異歸因於新設計。
- 審閱是否保留理解所需的否定、條件、指稱、縮約與語域；是否減少跨欄重複、無價值學習點與例句。
- 觀察學習者是否看懂原句、能指出表達何時適用、是否常找不到必要解說；產品不必加入作答／測驗流程才能做理解訪談。
- 分別衡量初始顯示量與生成總量。已有折疊不代表生成量已合適；內容少也不代表品質好。
- 先前對話的「每場景 2～3 點」或「每句 1～2 類」只能作為試驗起點，不是研究證明的最佳數字，不應直接當作永久硬性配額。

本次沒有驗證長期記憶、自由口說或十二種語言的效果，沒有用測試／建置結果代替真實教學品質。
