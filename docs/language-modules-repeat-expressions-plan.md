## 1. 目標與範圍

讓使用者透過可選擇的語言教學內容模組，從影片理解字詞、文法、語氣與讀音。各目標語言有自己的教學策略，並把同一部影片中重複出現的學習表達整理在一起：同一表達只教一次，保留每次原片出現的位置與上下文。

第一版包含：

- 共用學習引擎，目前支援的 12 種目標語言各有基本專用教學策略：英、日、韓、西班牙、法、德、義大利、葡萄牙、印尼、泰、馬來與越南語。
- 提供「字詞與表達、文法與句型、語氣與用法、讀音提示」四個教學內容模組，首次使用全部啟用；可選擇本次特別著重的一項，預設均衡。
- 對已選出的學習表達，搜尋這次課程所保存的全部字幕，不限於精選場景。
- 整理相同表達的出現次數、原句、相鄰字幕與可用時間點。
- 在學習表達下展開出現清單，並使用既有影片控制流程回看。
- 維持現有課程數量、例句數量、原文保留及字幕證據規則。

後續擴充：表達變形、同一句型、逐次用法比較，以及各語言更深入的教學策略。學習方式是閱讀情境解說、對照原片與例句、重聽及比較出現位置；不設計練習題、作答、測驗或評分。跨集／整季索引、已知詞追蹤與音訊辨識不在本次範圍。

第一版從已選出的教學表達建立出現清單，不宣稱已列出字幕中所有可能的重複片語。全片自動探索重複學習項目可另行規劃。

## 2. 現有基礎與缺口

目前已有候選片段、全片篩選、情境教學三階段；課程保留輸入字幕、字幕 ID、時間與精選表達。篩選階段會避免重複的教學表達。

目前缺少各語言的選材／教學策略模組、使用者可選的教學內容模組，以及每個表達的全部出現記錄。日／韓已有不同讀音規則，可納入模組；各語言不另建完整生成流程。

課程保存的是此次輸入的字幕範圍。完整影片分析才可標示「完整影片字幕」；部分分析標示實際範圍。未取得的字幕不可計入，也不可宣稱整部影片已搜尋完畢。

## 3. 語言模組的職責

共用引擎負責字幕來源驗證、時間解析、分段、數量限制、教學去重、JSON 驗證、保存與任務續跑。

語言模組負責：

| 面向 | 英文                             | 日文                                     | 韓文                             |
| ---- | -------------------------------- | ---------------------------------------- | -------------------------------- |
| 選材 | 日常搭配、片語、語用、口語句型   | 助詞、句尾、縮約、省略、固定句型         | 語尾、敬語層級、助詞、口語縮略   |
| 解釋 | 本段對話中的功能、語氣與適用場合 | 原文形式、必要的基本形式、語氣與禮貌程度 | 語尾與語氣、使用對象及場合       |
| 程度 | CEFR 對應的教學負擔              | JLPT 對應的教學負擔                      | TOPIK 對應的教學負擔             |
| 例句 | 保留目標用法並控制新詞與文法     | 保留目標句型／語體並控制負擔             | 保留目標用法／敬語層級並控制負擔 |
| 讀音 | 可靠 IPA，不推斷原片實際語調     | 假名、漢字與助詞的語境讀音               | 韓文讀音與可靠音變               |

目標語言決定教學模組；解釋語言決定說明文字。介面語言、解釋語言不替代目標語言，也不等同學習者母語。

上表是三種語言的例子，不限制支援範圍。其他語言同樣在第一版有基本專用策略，例如西班牙／義大利／葡萄牙文的動詞與代名詞、法文的口語省略、德文語序與可分動詞、印尼／馬來文詞綴與口語形式、泰／越南文的語氣與稱謂。後續逐步深化辨識規則，不讓其他語言長期只使用通用提示詞。

### 教學內容模組與使用者選項

語言策略和教學內容是兩個維度：目標語言決定如何教，使用者勾選的模組決定本次著重哪些內容。這些是解說內容模組，不是練習題模組。

| 模組       | 教學內容                       | 語言適配例子                              |
| ---------- | ------------------------------ | ----------------------------------------- |
| 字詞與表達 | 詞義、搭配、片語、固定表達     | 英文片語動詞、各語言常用搭配              |
| 文法與句型 | 結構、變形、省略、口語縮約     | 日文助詞與縮約、德文語序                  |
| 語氣與用法 | 表達目的、禮貌程度、適用場合   | 婉拒、委婉建議、韓文敬語                  |
| 讀音提示   | 可靠讀音、文字能支持的發音規則 | IPA、假名、韓文音變；不聲稱已分析原片音訊 |

選項行為：

- 首次使用四項全開，「本次著重」為均衡；全部啟用代表綜合選材，不要求每個片段都填滿四類解說。
- 可取消不需要的教學內容，至少保留一項。可從已啟用模組選一項作為主要重點；停用該項時回到均衡。
- 選項同時影響候選、篩選與解釋。只著重文法時優先找有實用句型的片段，保留理解該句必需的簡短詞義說明。
- 原文、基本意思、字幕證據與原片回看是共用基礎，不因某個內容模組停用而消失。停用讀音提示則不要求生成讀音註記。
- 保存偏好供下一次使用。修改偏好影響新生成內容，不自動改寫舊課程，也不在舊課程中假造缺少的模組解說。
- 相同影片中的各次出現提供對照素材，仍須區分不同語境的意思；AI 例句是輔助解說，標明來源，不要求使用者作答。

程度只提供難度估計，沒有已知詞資料時，不宣稱精準 i+1。各語言程度尺度不直接互換。

設計上提供小型模組介面：取得指定語言、程度、啟用內容與主要重點的教學策略，以及搜尋指定表達的出現位置。共同搜尋邏輯由內部 helper 共用；語言專用規則留在各自模組，避免在各階段增加分散的語言判斷。

建議位置：`apps/local-host/src/generation/language-modules/` 放教學策略；`packages/core/src/` 放可供 Host 與 Extension 共用的出現記錄型別與純搜尋邏輯。具體檔案命名於實作時依現有結構確認。

## 4. 提示詞調整

現有三階段保留，各階段注入適用的語言教學策略、啟用的內容模組與主要重點：

1. 候選：按目標語言與程度找可重用、上下文清楚的表達。
2. 篩選：綜合情境價值、程度適合度、對話功能多樣性；同一教學表達不重複占用名額。
3. 教學：按啟用模組解釋字詞、文法、語氣或讀音；說清楚這裡在回應什麼、為何用此表達、如何移用。例句遵循該語言的程度與語體規則，不生成題目或作答要求。

保留字幕／標題不可信、不得改寫原文、不得編造時間或人物關係的規則。只有容易誤解時才補充字面義差異，證據不足時不斷言意圖或情緒。

原句與片語必須引用實際字幕。抽象句型（例如 `まだ〜ていない`）不得假裝成原文出現的表達。

## 5. 單部影片的出現記錄

流程：選出教學表達 → 搜尋已保存字幕 → 整理每次出現 → 在該表達下展示。

第一版搜尋規則：

- 以相同文字表達為主，允許受控的排版差異，例如英文大小寫、直／彎引號與空白；保留原文並維護正規化後位置至原文字元的對應。
- 使用適合該語言的比對規則；英文短詞不能誤命中其他詞的一部分，也不以空白切詞假設日／韓一定有詞界。
- 支援完整表達跨相鄰字幕行，但不跨明顯時間斷點拼成不存在的一句。無時間輸入只按相鄰字幕搜尋。
- `figure out` 與 `figured it out` 等變形，第一版不自動視為同一文字表達。
- 只移除重複引用同一來源位置的記錄；不同時間重說同一句仍要計數。影片 URL／標題本身不足以辨識字幕版本。
- 同文不代表同義。第一版展示各次上下文，不自動為所有出現套用第一個場景的解釋。

每次出現至少可解析：

| 資料                   | 用途                           |
| ---------------------- | ------------------------------ |
| 原始字幕 ID 與字元範圍 | 區分實際出現位置，避免重複計數 |
| 原文片段               | 呈現影片實際文字               |
| 上下文字幕 ID          | 比較前後對話                   |
| 字幕時間範圍或空值     | 回看；無時間內容仍可查閱       |

播放時間由原始字幕解析；跨行表達使用首尾字幕時間，不編造詞級時間。既有校準可影響實際回看範圍，但不改動來源時間或出現計數。

第一版從課程已有 `cues` 即時計算並按需快取出現記錄，沿用 V5 儲存格式。JSON 匯出／匯入與備份保留原字幕後即可重新計算，不需要資料遷移或額外模型呼叫。舊課程可搜尋已保存的表達，但無法憑空補回未保存的字幕。

搜尋快取綁定字幕內容、表達、語言與比對規則版本；切換影片／字幕／課程不能沿用舊結果。

## 6. 閱讀介面

產生課程前提供學習重點選項；課程中按實際生成的教學模組呈現解說，可收合較長內容。切換顯示不代表已生成其他模組，避免空白區塊或誤導性的開關。

在現有學習表達下增加「原片出現 N 次」入口：

- 預設收合，依字幕順序列出各次原句與時間，展開可看相鄰字幕。
- 次數按實際匹配位置計算；只有一次時清楚表示一次，不稱為重複出現。
- 顯示搜尋涵蓋的字幕範圍，避免部分分析看起來像完整影片。
- 有時間與已確認相符的影片連線時，使用既有播放／定位流程回看；錯誤影片不可直接定位。無時間時保留文字查閱。
- 翻譯只顯示已有資料；其他位置不套用第一個場景的翻譯，也不假造尚未生成的解釋。
- 保持窄側欄可讀、鍵盤可操作，出現很多次時分批展開。

後續可加入逐次用法比較：針對使用者選取的少量出現位置生成解釋、保留來源 ID 並快取。語義不明的例子維持未判定，AI 新例句與原片實例分開呈現。

## 7. 相容性與版本

- 保持既有 V5 課程可讀與既有閱讀流程；出現搜尋不需要改動舊課程格式。
- 使用者選用的模組與主要重點隨生成請求保存，納入執行快照／輸入識別，避免續跑中改變。舊偏好／請求缺少選項時有明確相容預設。
- 實作時確認現有內容欄位能否充分保存文法與語用解說；若不足，設計向後相容的可選模組說明欄位並驗證匯出／匯入與備份，不只靠提示詞增加會被丟棄的資料。
- 新教學策略只影響之後生成的教材，舊課程不因讀取而自動改寫。
- 提示詞版本包含共用提示詞與實際使用的語言策略版本。建立任務與續跑檢查使用同一版本識別來源。
- 既有執行快照不相容時沿用明確的續跑拒絕／重新建立任務流程，保留已有成果，不混用不同教學策略。
- 12 種現有目標語言均有基本專用策略；通用策略只承載共用規則，不替代個別語言的基本教學策略。

## 8. 實作順序與驗收

| 階段              | 交付內容                                                            | 驗收重點                                                                         |
| ----------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| A：語言與內容模組 | 12 種語言基本策略、四類教學內容選項、主要重點、三階段注入與版本識別 | 首次全開／均衡；至少一項；目標／解釋語言獨立；偏好與請求可保存；不相容任務不混用 |
| B：出現搜尋       | 純搜尋邏輯、來源位置、上下文、計數與快取                            | 重複／跨行／排版差異／詞界／字幕斷點／無時間／切換輸入                           |
| C：閱讀介面       | 模組解說呈現、出現入口、清單、範圍說明、回看整合                    | 模組解說可閱讀且無作答流程；原文與時間正確；錯誤影片不定位；窄側欄與鍵盤操作     |
| D：後續擴充       | 語言專用變形與句型、按需用法比較                                    | 原文與抽象模式分開；同文不同義不誤合併；增量生成並快取                           |

程式驗證需覆蓋外部行為與來源不變量，避免只測提示詞字串是否包含某句話。12 種語言都要有固定字幕案例，逐語言確認基本策略與模組選項；模型品質評估可分批進行，但未驗證語言需明確標示。比較修改前後的選材、解釋、語體與例句品質，並確認全部啟用不會強迫產生無關解說。模型品質評估與程式測試分開報告。

播放驗收另用實際連線的瀏覽器與影片確認。測試／typecheck／build 通過不代表已驗證 Netflix／YouTube 的原片定位。

本規劃不估工期；A～C 為第一版，D 待第一版生成品質與使用體驗驗證後再做。
