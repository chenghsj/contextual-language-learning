# 中文學習語言

學習目標新增 `zh-TW`（中文／台灣／繁體）與 `zh-CN`（中文／中國／簡體），與介面、解說及系統朗讀語言分別保存。兩者使用既有 A1–C2 教材難度，預設 B1；不宣稱對應 TOCFL 或 HSK 級別。

V5、V6 的中文教學策略涵蓋有意義的詞／構式、量詞、時貌助詞、語序、補語、省略與句末語氣。字幕引文與 UTF-16 範圍保持原樣；AI 例句依所選繁簡／地區產生，不自動轉換來源文字。

發音啟用時，`zh-TW` 保存帶聲調注音，閱讀器提供「注音／關閉」；`zh-CN` 保存帶聲調符號的漢語拼音，閱讀器提供「漢語拼音／關閉」。多音字依上下文，姓名或不可靠讀音省略。沒有音訊分析，不能宣稱影片中的實際變調或語調。既有 reading 欄位、對齊驗證與一次局部修復流程沿用，無須教材 schema 遷移；格式檢查不證明讀音語意正確。

注音格式參考 [教育部國語注音符號手冊](https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html)；拼音使用聲調符號，而非數字調號。

Netflix／YouTube 字幕匹配辨識 `zh-TW`／`zh-Hant` 與 `zh-CN`／`zh-Hans`，不交叉繁簡；無法判斷文字系統的裸 `zh` 不自動匹配，可由使用者匯入並指定語言。片語比對支援無空格中文與相鄰字幕，保留原文偏移與時間，長時間間隔仍切斷匹配。
