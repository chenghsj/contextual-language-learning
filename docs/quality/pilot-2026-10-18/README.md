## 最需要處理的問題

1. **保留省略與指涉的不確定性。** 日文 `「時間を教えて」って。` 沒有提供說話者性別，輸出卻在翻譯和逐句句意都寫成「她說」。摘要與解說也會加入來源沒有確立的視覺行為。需要逐欄位修正，不能只在最後補一則總提醒。
2. **區分可靠框架與損壞文字。** `悪いない` 在受影響翻譯、句意及可重用來源表達中都沒有標為不明，因此固定覆蓋檢查失敗。輸出並沒有猜出這個詞的意思；周邊 `って何？` 可以教，但不能把整個損壞引文呈現為可靠範例。
3. **驗算可重用句型。** 輸出 `[動詞て形省略い]てた？`，代入 `話して` 會得到 `話しててた`。正確的具體例句不能抵銷錯誤模板；需從完整的 `〜ていた／〜でいた` 說明只省略 `い`，並檢查兩種詞尾。現有規則已要求這項檢查，這輪仍未遵守。

前兩組的「畫面／看到」問題依本輪嚴格的純文字來源準則判定；它們不是語法錯誤。日文不確定情境另有明確的性別補寫與模板錯誤，因此即使放寬視覺措辭，該組仍不能接受。
