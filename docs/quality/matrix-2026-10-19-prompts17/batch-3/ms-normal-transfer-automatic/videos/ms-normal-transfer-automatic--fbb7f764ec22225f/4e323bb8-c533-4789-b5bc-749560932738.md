## 出門前的通話

對話包含詢問對方為何仍在此處、說明剛打算出門時接到電話的情況、請求稍作等待，以及肯定的回應。

> Kenapa kamu masih di sini?
> 你為什麼還在這裡？
> Saya baru hendak keluar ketika kamu menelefon.
> 你打電話來的時候，我才剛要出門。

- **Saya** — 我
- **baru hendak** — 剛正要
- **keluar** — 出門
- **ketika** — 當……的時候
- **kamu menelefon** — 你打電話
- Core explanation: **baru hendak 的時態用法** — 「baru hendak」表示「剛打算」或「剛正要」做某事，後接動詞原形。在句中說明動作剛要發生時正好碰上另一事件（如接到電話）。
