## 臨時的等待請求

對話包含詢問對方為何仍在現場、說明接到電話時正打算離開的情況，以及請求稍候與答應的互動。

> Kenapa kamu masih di sini?
> 你怎麼還在這裡？
> Aku baru mau pergi waktu kamu menelepon.
> 你打電話來的時候，我剛好正要離開。

- **baru mau** — 剛好正要
- **waktu kamu menelepon** — 當你打電話的時候
- Core explanation: **「baru mau」表示正要進行某動作** — 「baru」（剛剛）與「mau」（將要、打算）連用，表示某個動作或計畫在該時間點「剛好正打算進行」，常用於說明事情發生的時間巧合或打斷前的狀態。

> Bisa tunggu sebentar?

- Core explanation: **常用口語片語「tunggu sebentar」** — 由動詞「tunggu」（等）與時間詞「sebentar」（一下子、一會兒）組成，為日常請求他人稍候時極為常見的固定用法。
