### “Tolong beri tahu waktunya,” katanya.


- **Tolong** — 請
- **beri tahu** — 告訴、通知
- **waktunya** — 時間
- **katanya** — 對方說
- Core explanation: **常用片語 beri tahu（告訴、通知）** — 由動詞 beri（給）與 tahu（知道）組合而成的常用片語，表示「告知、通知某人某事」，口語常與 tolong 連用以構成禮貌請求。

### Ngomong-ngomong, sudah makan?


- **Ngomong-ngomong** — 順便一提、話說回來

- Core explanation: **以 ngomong-ngomong 自然轉換話題** — 口語中用來轉換話題的標記詞，相當於中文的「順便一提」、「話說回來」，用於在結束前一件事後帶入新的對話內容。
