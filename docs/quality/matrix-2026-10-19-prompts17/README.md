## 設定、來源及原始證據

Antigravity `gemini-3.8-flash`／`medium`，`learning-points-prompts-17`、`learning-points-v7-1`、`program-validation-2`、protocol 12。解說語言為繁體中文，來源使用保留的固定合成對話，每個可重用項目一組新例句。韓文程度 3、日文 N3，其餘固定案例為 B1。

新增 24 組分為四批，每批三種語言、六組案例，最多同時執行兩批。每組只進行一次完整生成；沒有整組重跑、挑選替代輸出、provider fallback 或中途修改 prompt。批次條件、固定請求、原始報告、任務與最終教材保存在 `batch-1` 至 `batch-4`；[run-context.json](./run-context.json) 記錄來源 tree、雜湊、批次及沿用四組的依據。

本次矩陣的 89 個原始檔案以 [raw-artifacts.sha256.json](./raw-artifacts.sha256.json) 鎖定位元組；沿用四組的原始證據由其自身的 manifest 與核對工具驗證。原始 `report.json` 的待語意審查欄位未被改寫；生成、覆蓋核對及最終接受判定分別保存。所有逐項審查使用 [同一份準則](./review-rubric.md)。

Runner 保存最終任務、教材、呼叫與診斷資料，但未保存被拒絕的中間模型回應或全部成功修復的觸發細節。因此只能確認修復步驟及已回報用量，不能重建每次初始錯誤，也不能將執行紀錄數視為底層 HTTP 嘗試次數。
