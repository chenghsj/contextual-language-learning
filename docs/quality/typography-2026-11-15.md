# 擴充功能字級檢查（2026-11-15）

依 [DESIGN.md](../../DESIGN.md) 檢查擴充功能所有頁面的文字角色，並核對共用 UI、Markdown 與閱讀器的繼承樣式。檢查包含原始碼及以模擬服務執行的實際元件；未重新載入使用者 Chrome 中的已安裝擴充功能。

| 角色                            | 基準字級／行高               |
| ------------------------------- | ---------------------------- |
| 正文、必要操作說明、主要錯誤    | 14px／約 23px                |
| 學習原文與例句                  | 15px／32px                   |
| 頁面與區塊標題                  | 14px／20px、600 字重         |
| 欄位標籤、短提示、精簡控制項    | 12px／16px；多行提示加大行距 |
| 日期、時間、計數與執行 metadata | 11px／16px                   |

日文 ruby 8px、其他讀音 10px，以及 Markdown 文件的 20／18／16px 標題，沿用既有規範的例外。

## 修正內容

- 進階設定、建立摘要、設定子區塊與彈窗使用對應的標題、正文與標籤角色。錯誤、必要操作說明與空狀態不再沿用 12px 標籤字級。
- 服務名稱移除 13px，時間與計數移除 10px，次要資料改用共用 metadata 角色。精簡按鈕保留 12px，輸入與一般選項保留 14px。
- 共用樣式合併工具辨識產品字級，避免文字顏色移除字級、或元件預設字級覆蓋呼叫端設定。擴充功能共用同一個 `cn`，並加入字級與顏色合併的回歸測試。
- 摺疊元件可直接指定觸發文字的角色；Dialog 與通知有產品字級預設值。Markdown 不再以父層樣式覆蓋個別語言的 ruby 字級。
- 視窗高度不超過 400px 時，閱讀器對話工具列隨內容捲動，避免遮住解讀操作；底部播放器維持固定。
