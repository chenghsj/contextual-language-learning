## 道歉與話題轉換

一人為自己剛才說話口氣太重向對方道歉，另一人表示理解並提及ヒカル的漫畫（後半句語意不明），接著將話題轉向自己之前就很在意的一件事。

> ごめんね。きつい言い方して。
> 對不起。我說話太重了。
> Pronunciation: ごめんね (ごめんね)。きつい (きつい)言い方 (いいかた)して (して)。

為自己說話語氣過於嚴厲向對方道歉。

- **ごめんね** — 對不起
- **きつい言い方して** — 說話口氣太重
- Core explanation: **きつい言い方して（說話口氣太重）** — 「きつい」在此形容言語尖銳、不留情面。「きつい言い方して」接在道歉語「ごめんね」之後，以動詞「て形」補充說明道歉的原因（口語省略了助詞「を」），常用於反省自己剛才語氣過於嚴厲時。

> それより前から気になることがある。

將話題轉移到自己從之前就一直掛念的事情上。

轉移剛才的道歉話題，開啟自己想要討論的新事項。

- **それより** — 比起那個
- **前から** — 從之前就
- **気になる** — 在意的、掛念的
- **ことがある** — 有一件事
- Core explanation: **それより（比起那個、話說回來）** — 用於轉換話題，將對話焦點從前述內容移開，引出說話者目前更重視或更想詢問的事項，相當於「比起剛才那件事」、「話說回來」。
- Core explanation: **気になる（在意的、掛念）** — 表示某件事停留在心頭，讓人放不下心、掛念或感到好奇。與說話者自主刻意去介意的「気にする」不同，「気になる」著重於自然產生的在意或惦記。
