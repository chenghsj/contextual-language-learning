# 全產品過場動畫實作計畫

狀態：已實作。此文件保留動態規格與實作要求；實際驗證範圍見 [驗證紀錄](quality/ui-motion/verification.md)。

## 目標與範圍

讓切頁、深入子頁、返回與內容展開具有一致的連續感。保留目前的設定文字列表、間距、分隔線、內容順序與所有操作，不重新設計版面。

適用建立內容、內容庫、標準／自訂閱讀器、設定及子頁、活動及詳情、字幕預覽／編輯器、Dialog、Popover、Accordion 與通知。

## 動態規格

| 操作                                 | 呈現                                                                           | 時間                   |
| ------------------------------------ | ------------------------------------------------------------------------------ | ---------------------- |
| 設定／活動 Sheet 開啟與關閉          | 沿用右側滑入／滑出及遮罩同步淡化                                               | 開啟 320ms，關閉 240ms |
| 建立內容 ↔ 內容庫                    | 新的主要內容短暫淡入，保留主標頭及導覽位置                                     | 240ms                  |
| 建立流程前進／返回                   | 新步驟由右／左側 12px 處移入並淡入；步驟導覽及 Footer 固定                     | 前進 280ms，返回 240ms |
| 設定首頁 ↔ 子頁、一般設定 ↔ 聲音資源 | 內容由右／左側 12px 處移入並淡入；Header 固定，標題直接更新                    | 前進 280ms，返回 240ms |
| 活動列表 ↔ 執行詳情                  | 同設定層級過場；活動狀態更新不觸發切頁動畫                                     | 前進 280ms，返回 240ms |
| 內容庫 ↔ 標準／自訂閱讀器            | 新內容淡入，標頭及播放器直接定位；保留既有返回行為                             | 240ms                  |
| 閱讀器切換場景                       | 僅新場景正文淡入；標頭、場景選擇器及播放器固定                                 | 240ms                  |
| 字幕預覽／編輯器進入與返回           | 主要內容前進／返回過場，保留編輯 Dialog 的獨立行為                             | 280／240ms             |
| AI 例句、活動細節、進階設定          | Accordion 高度展開／收合及箭頭旋轉；活動列保留原有 hidden 契約，收起時立即隱藏 | 160–200ms              |
| Dialog／Popover／通知                | 沿用既有動畫及定位，補齊減少動態效果支援；不疊加第二套進場動畫                 | 120–200ms              |

例行動畫使用柔和減速，例如 `cubic-bezier(0.16, 1, 0.3, 1)`；退出比進入快。列表不逐項延遲出現，重整不重播整份列表。影片字幕、計時、播放進度、模型及備份狀態即時更新，不重播整區動畫。

第一版切換主內容採「舊畫面立即切走，新內容進場」，不做兩份互動 DOM 同時存在的交叉淡化。這樣可保留現有 React 狀態、唯一的欄位 ID、焦點與捲動規則，也不延後切頁或播放操作。

## 動畫效果設定

位置為「設定 → 一般 → 介面設定」，排列在外觀模式後方。使用現有 Switch，欄位名稱為「減少動態效果」。依使用者回饋將三選項簡化為一個開關。

| 開關         | 儲存值    | 行為                                                       |
| ------------ | --------- | ---------------------------------------------------------- |
| 開啟         | `reduced` | 關閉滑動、縮放、高度展開及非必要的進出場動畫，內容直接切換 |
| 關閉（預設） | `full`    | 使用完整過場                                               |

欄位說明為「減少所有頁面的過場與非必要動畫。」名稱與說明涵蓋現有五種介面語言。開關獨立於系統設定，無需至作業系統調整。

- 使用者切換後立即套用，正在播放的過場取消並顯示目前狀態；選項變更本身不觸發一次全頁進場。
- 減少動態效果保留清楚的處理中、完成、失敗、選取及焦點回饋。非必要的旋轉與脈動停止，以靜態圖示和在地化狀態文字表達；真實影片及系統朗讀不因動畫偏好而停播或改速。

### 儲存與套用

- 在 `packages/core/src/preferences.ts` 新增 `motionPreference`，沿用 `preferencesV2` 與現有 PreferencesStore；不新增獨立 localStorage 或 Native Host 協定。
- `defaultPreferences()`、schema 及舊資料缺少欄位時均預設為 `full`；舊版 `system` 與無效值也回退 `full`，不因單一欄位損壞捨棄其他有效偏好。
- `App.tsx` 配合既有載入、寫入排序與失敗回復流程，保存選項並套用解析後的有效模式；儲存失敗需回復已成功保存的選項並顯示既有錯誤回饋。
- 開關統一得到 `full` 或 `reduced`，供 CSS 與動畫 hook 使用；有效模式設在 `document.documentElement`，涵蓋 Portal 顯示的 Sheet、Dialog、Popover 與通知。偏好尚未載入時預設完整動畫。
- 盤點既有 `motion-reduce:*` 與系統偏好分支，避免 App 選擇完整動畫後仍被原始 media query 阻止，或只關掉正文而浮層繼續移動。
- 取消的是動畫，不可全域清除 `transform`：Dialog 置中、Popover 定位等必要 transform 必須保留。保留動畫結束／取消後的卸載、關閉及焦點回復流程。

## 實作順序

1. **先完成偏好與共用動態規則。** 加入減少動態效果 Switch、偏好 schema／預設值／保存與共用解析，覆蓋開關兩種狀態與舊資料轉換。在 `styles.css` 定義時間、距離及 easing；以小型共用 hook 驅動可中斷的內容進場。可使用原生 Web Animations API 配合現有 CSS／tw-animate-css，不新增動畫套件。動畫未執行或取消時，內容仍以正常可見狀態呈現。
2. **完成設定與活動過場。** 由 `App.tsx` 的 `settingsSection` 與活動詳情狀態決定層級及方向；涵蓋聲音資源頁。Sheet 開關時間在 App 使用處覆寫，保留共享元件結構。確認返回、關閉、焦點與既有捲動回復。
3. **完成建立流程與主要頁面。** 處理 `createStep`、建立／內容庫切換、字幕預覽與閱讀器入口。以啟用狀態決定是否進場，保留現有 hidden／持續掛載的表單，避免重設輸入、編輯草稿及驗證狀態。
4. **完成閱讀器與局部展開。** `contextual-scene-reader.tsx` 以場景識別決定正文淡入；`custom-viewer.tsx` 僅在進入文件時觸發。播放狀態輪詢、語音、時間軸、翻譯開關及原地片段切換不重播場景過場。統一既有浮層及展開的動態與減少動態效果行為。
5. **驗證與更新文件。** 將正式規格加入 `DESIGN.md`，驗證結果記入 `docs/quality/ui-standards/verification.md`，附實際 viewport、動畫量測及必要的錄影／截圖。

## 狀態與可及性要求

- 依導航／場景識別觸發，不以所有 render、資料刷新或 loading 更新作為動畫來源。
- 不以替換父層 React key 的方式重掛整個 App、表單、閱讀器或播放器；動畫包裝不改變 flex 的 min-height、主捲動區及固定 Header／Footer。
- 新導航立即採用最新目標並取消舊動畫，取消或 unmount 不留下透明、位移或等待中的內容。動畫不以 disabled 鎖住導航。
- 共用解析結果為 `reduced` 時，取消非必要動畫並直接顯示內容，必要狀態回饋仍清楚可見。
- 維持原生鍵盤及螢幕閱讀器順序，只有當前內容可操作。過場不能延遲焦點回復或使隱藏頁面的欄位重新可聚焦。
- 保留現有的捲動契約：切換場景回頂端、設定聲音資源返回回復位置、Sheet 關閉回復來源焦點；不藉新增動畫順便改變其餘頁面的捲動策略。

## 驗收與完成條件

- Typecheck、production build 與受影響頁面的既有測試通過。針對新增動畫 hook，補可中斷、卸載清理、相同識別不重播與減少動態效果的行為測試。
- 測試開關兩種狀態與系統偏好互不影響、舊資料相容、無效值回退、重新開啟後保留選項，以及儲存失敗回復。
- 一般設定中操作開關並立即開啟 Sheet／Dialog／Popover、展開 Accordion、切換頁面及場景，確認所有動畫來源遵循同一有效模式；切換模式不影響焦點、播放及草稿。
- 更新 `ux-layout-acceptance.mjs` 中 Sheet 原有 500／300ms 的期待，並檢查開關結束後的實際狀態；保留 Dialog、閱讀器及焦點驗證。
- 實際瀏覽器檢查 320／390／555／900px、320px 高短視窗、淺／深色及 normal／reduced motion；檢查繁中、日文與長描述、長路徑。
- 快速前進→返回→前進、動畫中關閉 Sheet、滑鼠與鍵盤導航均採用最後一次操作；沒有殘留舊畫面、焦點遺失或重複控制項。
- 表單值、字幕編輯、活動資料與閱讀狀態持續保留；字幕、時間軸、影片及語音播放不因過場被額外啟動、停止或重設。
- 固定標頭／播放器位置穩定，正文有可用的捲動空間，沒有新增水平捲軸或第二個頁面捲軸。
- 分兩輪驗證：首次批次檢查並集中修正，再確認一次。預覽資料與模擬 Host 的驗證，與安裝版擴充功能／真實影片播放驗收分開記錄。
