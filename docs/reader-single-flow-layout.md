# 閱讀介面：單一路徑

依 2026-10-15 對話中確認的 Markdown 結構實作；該結構取代先前三張概念圖，並非以概念圖作為像素比對目標。

字體、間距、控制尺寸及各頁版面共用 [全產品介面規範](../DESIGN.md)。本文只補充閱讀器的內容順序與操作行為。

## 內容與順序

1. 場景資訊：標題、場景切換、情境說明。
2. 完整原文：依字幕順序呈現，保留讀音、逐句翻譯開關、影片單句播放與原文系統朗讀。
3. 局部查閱：點原文片段後，於完整來源後、整句內容前顯示片段原文、意思、作用與系統朗讀。朗讀統一使用 icon，片段的朗讀 icon 放在片段原文旁；保留滑鼠提示與無障礙標籤。點另一片段更新同一區；再次點選同一片段可收起，焦點留在來源片段，不主動捲動。不另外提供關閉按鈕，原文下方的提示說明再次點選可收起。
4. 整句意思與情境解釋：來源群組展開後呈現，沿用現有去重規則。
5. 核心解說：隨來源群組一起開合，展開後呈現完整內容，長文依既有邏輯分段。「解說重點」維持普通標題，不另設收合開關。
6. 更多解說、AI 延伸例句、本影片其他出現：有內容才提供展開入口，各區可以獨立展開。AI 例句依片語／句型分區，以淡底標題、邊框與區間留白區分；同一片語的多段例句以分隔線區分。每段例句的整段朗讀 icon 放在情境說明右側，逐句朗讀留在各句旁，翻譯開關置於該段底部。例句翻譯與原文逐句翻譯分開控制。
7. 固定底部播放器：保留播放目標、播放／暫停、循環、前後切換、速度、時間軸及進階選項。

來源群組預設收合。點原句文字、句子列或群組範圍列可開合整份解析；範圍列提供箭頭、鍵盤操作與 aria-expanded。跨字幕共用一個開關，解析仍放在最後一條來源下方。各群組可獨立開合，工具列提供全部展開／收合，切換教材或場景時重設為收合。播放與朗讀不改變開合狀態；點擊解析內容也不收合。

點選斷句會展開所屬群組並顯示片段查閱，再點相同片段只關閉片段查閱，保留整份解析；收合來源群組時清除其片段選取。保留目前閱讀順序與分隔線，不加回整段／片段模式切換、看整段或獨立的逐段對照區。

依全產品文字角色：原字幕、片段原文、AI 例句及來源標題使用 15px／32px；意思、翻譯、核心與延伸解說使用 14px／約 23px。區塊標籤保留 12px，透過字重與顏色區分層級。

## 邊界

- 一個完整語句可以跨字幕；同一來源可有多份解讀。保留現有來源分組、順序與最後來源錨點，不重新組字或改寫教材。
- 選取片段不過濾整句解說、例句或其他出現位置。片段區用於快速查閱意思與作用，詳細內容仍保留於下方原本的閱讀流程。
- 無讀音、無解說、無例句、無影片控制時沿用原有可用性判定，不補造內容或空入口。
- 不改生成、儲存、資料格式、影片連接或 Native Host 語音契約。

## 驗證

相關互動測試、閱讀呈現測試與模擬播放回歸通過。專案 typecheck 與擴充功能 build 通過。
